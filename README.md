Sistema de gerenciamento de biblioteca desenvolvido em Python utilizando Programação Orientada a Objetos e persistência de dados em JSON.

## ✨ Funcionalidades

- Cadastro de alunos
- Cadastro de livros
- Empréstimo de livros
- Devolução de livros
- Consulta de alunos
- Consulta de livros
- Persistência automática em JSON
- Carregamento automático dos dados ao iniciar o sistema

## 🛠️ Tecnologias utilizadas

- Python 3
- Programação Orientada a Objetos (POO)
- JSON
- Git
- GitHub

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/DanielBonin-vibe/Projeto_Biblioteca.git
```

Entre na pasta:

```bash
cd Projeto_Biblioteca
```

Execute o programa:

```bash
python main.py
```
